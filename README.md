# Zona Cero

Juego web de supervivencia por oleadas. Esta versión está publicada para que el equipo de Poki pueda abrirla y probarla desde el navegador.

## Jugar

Abre `https://jh9388530-lab.github.io/Zona_Cero/` y pulsa **Oleadas** en el menú inicial.

## Controles de escritorio

- **WASD:** moverse
- **Ratón:** apuntar y disparar
- **Espacio:** esquivar
- **R:** recargar
- **1–4 / rueda:** cambiar arma
- **P:** pausar
- **K:** mostrar u ocultar controles

En móvil, mueve con el pulgar izquierdo y apunta/dispara con el derecho. El menú **Cómo jugar** muestra controles y apoyos dentro del juego.

## Publicación

GitHub Pages sirve `index.html` desde la raíz de `main`. El juego integra Poki SDK v2 y continúa funcionando si el SDK no está disponible.
